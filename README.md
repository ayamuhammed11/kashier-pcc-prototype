# Kashier PCC Prototype

Static HTML prototype of the **Payment Configuration Container (PCC)** details page, with an **optional Note** on every action recorded in the Events log.

Open `index.html` in a browser. No build step.

- **Edit Container** opens the editable view (template, container settings, card credential, rates & fees). Clicking it again saves.
- **Save** and **Delete Container** ask for an optional note, shown inside the matching Events entry.
- Sidebar and tab links point to pages that are not part of this repo.
